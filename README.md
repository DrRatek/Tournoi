# Tournoi — Duels de beauté

Application web autonome (un seul fichier `index.html`, fonctionne hors ligne) pour classer ~250 actrices de la plus belle à la moins belle par duels successifs.

## Utilisation
Ouvrir `index.html` dans un navigateur.

- **Mes actrices** : importer vos photos une par une ou **en un seul fichier ZIP** (nommez chaque fichier d'après l'actrice, ex. `zendaya.jpg`), charger la liste d'exemple de 250 actrices, ou coller votre propre liste de noms.
- **Duels** : deux portraits plein écran côte à côte ; cliquez (ou ← →) sur la plus belle. Objectif : 12 duels minimum par actrice, appariements entre scores proches pour la précision. Annulation possible.
- **Classement** : podium + liste complète avec export CSV/JSON.
